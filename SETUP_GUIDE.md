# Setup Guide

## Необхідні інструменти

Для запуску демонстраційної версії To-Do App потрібні:

- комп'ютер або ноутбук;
- браузер Chrome або Firefox;
- підключення до Інтернету;
- акаунт користувача.

## Запуск вебверсії

1. Відкрийте браузер.
2. Перейдіть на сторінку To-Do App.
3. Натисніть **«Створити акаунт»**.
4. Вкажіть email і пароль.
5. Виконайте вхід.
6. Відкрийте сторінку **«Мої завдання»**.

## Локальний запуск

```bash
git clone https://github.com/example/todo-app.git
cd todo-app
npm install
npm run dev
```

Після запуску застосунок може бути доступний за адресою:

```text
http://localhost:3000
```

## Перевірка роботи

Система працює правильно, якщо:

1. відкривається головна сторінка;
2. можна створити нове завдання;
3. завдання з'являється у списку;
4. статус завдання можна змінити;
5. після оновлення сторінки дані не зникають.
