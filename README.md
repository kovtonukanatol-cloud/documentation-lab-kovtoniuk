# To-Do App

## Опис проєкту

**To-Do App** — простий трекер завдань для планування особистих справ, навчання та невеликих робочих задач.

Застосунок допомагає користувачу не забувати важливі справи, контролювати дедлайни та бачити, які завдання вже виконані.

## Основні функції

- створення нових завдань;
- редагування та видалення завдань;
- встановлення дедлайну;
- вибір пріоритету;
- позначення завдання як виконаного;
- фільтрація завдань за статусом.

## Для кого цей продукт

To-Do App орієнтований на студентів, працівників невеликих команд та користувачів, які хочуть планувати особисті справи.

## Приклад завдання

| Назва | Пріоритет | Статус |
|---|---|---|
| Виконати лабораторну роботу | Високий | У процесі |
| Купити продукти | Середній | Не виконано |
| Перевірити пошту | Низький | Виконано |
